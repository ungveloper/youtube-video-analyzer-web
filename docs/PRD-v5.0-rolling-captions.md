# v5.0 — Normalize YouTube rolling automatic caption displays

## Actual failure

After v4.9, YouTube subtitles were found (75 cues / ~191 s) and the `caption_first` path was used. The output had A+B and B+C rolling caption repetition. Example: `뇌혈관 질환을 먼저 떠올립니다. 하지만...` overlapped the previous cue; in the middle, `많은 환자분들이 허리 질환` and the following `특히 젊은 사람들은 디스크 탈출증` were repeated across multiple cues. This is **not** Gemini speech hallucination. The text-only article composition separately returned 503, leaving an empty article; this patch deliberately does not change that provider failure behavior.

## Implementation

- Only `lib/server/ytdlp-captions.ts` production code changes.
- Parse VTT cue order and exact text; detect rolling tracks by recurring exact multi-word suffix/prefix overlaps, not vague topical semantic similarity.
- For rolling tracks only, remove overlap and group newly revealed words into chronologically ordered sentence-length cues. Keep all newly revealed words verbatim and once, with caption-derived approximate group times.
- Do NOT replace known words, silently fix medical terminology, invent timestamp-aligned audio, or join unrelated nonrolling subtitle tracks.
- Preserve existing 28-cue human-edited LiveWiki-style reference exactly, and preserve current automatic-caption fetch flow, Gemini behavior, free-tier quota guards and model-call count.
- Log `analysis.youtube_rolling_caption_normalized` before/after cue counts so real-world behavior is measurable.

## Verification

- Deterministically synthesize 67 rolling VTT windows from the full 28-cue user-provided LiveWiki sample; require that the *complete sequence of words* is preserved once (in order), while cue count reduces to 33.
- Test 02:08–02:31 medical contrast rolling overlap, final 02:47–03:11 overlap, and untouched 28 human-edited SRT cues.
- Run all existing regression tests, `npm run lint`, `npx tsc --noEmit`, `npm run build` on the user's actual repository before committing.

## Limits

YT autogenerated captions can mishear terminology (e.g., `동맹` instead of `동맥`), and VTT display timestamps do not certify word-level alignment. The grouped cue timestamps therefore derive from the displayed intervals and need manual checking for exact starts. A Gemini text-only 503 can still prevent article generation but must not erase the subtitles.
