# v1.5 — 플레이어 시간 이동 및 선택형 정밀 분석

2026-10-08 / 개인용 무료 Gemini API PoC.

## 주요 수정

1. 기존 `setStart()`와 iframe `src` 변경으로 플레이어가 다시 로드되던 문제를 제거한다.
2. 공식 YouTube IFrame Player API를 통해 `seekTo()`에 이어 `playVideo()`를 실행하고 준비 상태 이전의 클릭을 대기한다. 자동 재생 제한 및 YouTube 원본 링크를 안내한다.
3. 분석 깊이 선택: 기본 1회, 정밀 최대 2회 무료 Gemini API 호출. 정밀 모드에서는 정보가 적은 초안을 원본 영상과 두 번째로 검토한다.
4. 2차 결과 검증 실패, 할당량 제한 또는 타임아웃 시 성공한 1차 결과 유지. 부정확한 2차 결과를 완벽하다고 보증하지 않는다.
5. 비용: DB/Redis 추가 없음. 유료 전환 없음. 무료 API 입력량 최대 2회분을 소비할 수 있음.
6. 구버전 IndexedDB 결과 변경 없음. 적용 후 다시 분석해야 새 정책이 사용된다.

## 검증

- 타임스탬프 클릭 시 iframe `src`가 변하지 않을 것.
- `seekTo` 및 `playVideo`가 함께 호출될 것. 사용자 동작으로 자동 재생이 막히면 원본 타임스탬프 링크 이용 가능.
- 기본 모드 1회, 정밀 모드 최소 1회 최대 2회, 일시 장애 자동 재시도도 포함해 상한을 지킬 것.
- 두 번째 영상 검토 실패 시 첫 번째 결과 반환.
- 모델 응답의 근거 ID·시간 범위 검증 유지. 내용의 의미적 정확성은 사람이 영상과 대조할 것.
- 로컬에서 ESLint 경고 0건과 Next.js 프로덕션 빌드 통과 후 커밋·푸시할 것.
