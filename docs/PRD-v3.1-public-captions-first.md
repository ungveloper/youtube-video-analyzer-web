# v24 · 공개 시간 지정 자막 우선 및 무료 429 절약

- 근거: 2026-10-13 요청 로그의 standard 분석은 45.5초/1회로 성공했으나, speech-tail 2차 요청은 429 FREE_LIMIT. 기존 첫 응답에서 59~100초, 159~202초의 발화가 비어 있었고 1분 이후 시각은 검증되지 않았다.
- 공개 YouTube 영상에 접근 가능한 한국어 시간 지정 자막이 포함된 경우, 서버에서 공개 watch 페이지의 captionTracks와 공식 timedtext 엔드포인트를 읽는다. 쿠키·YouTube 로그인·인증정보·Redis·DB·사용자 데이터 저장은 없음. 5.5초 타임아웃, 인증 없이 접근할 수 있는 것만 사용.
- 허용 호스트 및 `/api/timedtext` 경로 검사와 1MB 크기 상한으로 임의 URL 조회 차단. 언어 `ko`, 길이·시작·끝·시간 공백 검사. 3:22 영상 자막이 1:58에서 종료되면 전체 자막으로 인정하지 않음.
- 자막 확보 시 Gemini Interactions에는 비디오 대신 시간 지정 발언 텍스트만 입력하여 요약·아티클 1회 생성, 타임라인은 코드에서 시간 지정 자막 자체를 그대로 사용. 모델 시각 조작 방지. 사용자 제공 자막과 공개 자막 출처를 표시에서 구분.
- 영상에 자막이 없거나 공개 자막 획득이 불가능하면 기존 URL 직접 분석으로 전환. 이때 불확실한 AI 추정 시각을 검증된 시각이라고 표시하지 않는다.
- 발언 보완의 두 번째 영상 요청 기본값을 꺼서 무료 할당량의 429가 반복되지 않도록 함. 사용자가 선택하면 최대 1회 허용하고 Static 비디오 processing.start_offset/end_offset으로 실제 영상 구간만 잘라 요청한다. URL clipping 지원 여부는 Google 실서비스에서 검증 필요.
- 기존 v23의 추가 보완 응답 중복·범위·밀집 시각 차단 유지. Sonner/세션 전용/무료 모델 정책 유지.
- 실서비스 접근 권한, 공개 자막 존재, Google Interactions 응답은 Mac에서 직접 확인 필요. 실제 자막이 없는 영상은 정확한 자동 전사를 보장하지 않음.
