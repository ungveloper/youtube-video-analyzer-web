# PRD v2.2 — 발언 단위 타임라인과 정확한 시간 표시

## 목표

- 주제별 큰 타임라인 문단을 나누어 **실제 확인 가능한 개별 발언/의미 전환**마다 한 행으로 나타냅니다.
- 시간은 `00:00`, `00:33`, `01:44`로 표시하며 클릭 시 기존 YouTube 플레이어의 해당 시작 시각으로 이동합니다.
- 문장에 대한 세밀한 시간 정보가 없을 때 시간을 균등 배분하거나 임의의 초를 만들지 않습니다. 동일한 근거에 속하면 동일한 시간 표시가 반복될 수 있습니다.
- **Gemini 추가 호출 없음**. 저장·Redis·DB 없음. 영상 URL 기본 분석 1회, 기존 정밀 분석 규칙 유지.

## 구현

1. **기본/URL 1회 모드:** 영상 근거 `evidence[].note`를 필수 출력으로 요청합니다. 하나의 타임라인 문단에 서로 다른 시간 근거와 충분히 구체적인 note가 여러 개 연결돼 있으면 해당 note별 행으로 분리합니다. 근거가 없거나 note가 부실하면 기존 텍스트를 보존합니다.
2. **정밀 2단계 모드:** 문서 작성 AI가 근거를 여러 개 뭉쳐서 하나의 주제 문단을 만들더라도, 원본 `claims[]`를 개별 근거 시각에 맞춰 복원합니다. 작성된 요약/아티클은 그대로 유지합니다.
3. **사용자 자막:** SRT/VTT 또는 타임스탬프 원문 입력 시 문장부호·발언 사이의 공백·짧은 시간 창을 우선으로 출처 근거를 나눕니다. 자막 큐 안의 개별 문장에 새 시각을 만들어 붙이지 않습니다.
4. **UI:** 큰 카드 대신 시간 버튼이 앞에 있는 세로 목록. 다운로드되는 Markdown/TXT/PDF/DOCX에도 타임스탬프를 본문 앞에 포함합니다.
5. **품질 진단:** 5분 이하는 타임라인 9개, 5~15분은 12개, 15~30분은 16개를 내용이 충분할 때의 편집 기준으로 평가합니다. 개수는 **목표**이며 생성 보장이 아닙니다.

## 알려진 한계

- URL만으로 Gemini가 시각이 다른 발언을 근거로 나누지 못했다면 추가 항목을 만들어낼 수 없습니다.
- 원본 타임스탬프의 정확성은 모델이 생성한 근거 시각에 의존합니다. 사용자 제공 자막의 시각도 자막 자체의 정확성을 보장하지 않습니다.
- 상세한 아티클 작성 기능이나 Gemini 제공자의 429/500/503 상황은 이번 타임라인 패치 범위 밖입니다.
