# YouTube AI Analyzer — PRD v1.0 (2026-10-08)

## 제품 비전

로그인 없이 공개 YouTube ID/URL을 입력하여 한국어 요약, 시간별 타임라인, 상세 해설형 아티클, 조건부 전사/번역 스크립트를 생성하고 편집/내보내기하는 무료 우선 웹 서비스. 향후 유료 SaaS 확장 고려.

| 회차 | 확정 항목 |

| 03 | 핵심 요약, 타임라인, 아티클, 스크립트. 상세 분석 및 해설형 아티클 |

## 비기능 요구사항

- 영상 근거가 없는 주장은 최종 결과에서 제외하며, 편집 시 근거 재검증 필요 표시.
- 정확한 스크립트 원문을 확보하지 못한 경우 스크립트를 만들어 내지 않음.
- 서버에 사용자 완료 분석 결과를 영구 보관하지 않음. 사용량·작업 상태는 보안 제한 하에 임시 보관.
- 무료 AI 한도 및 서버 장애는 fail-closed 처리; 기존 IndexedDB 결과 열람은 계속 유지.
- 사용자 수정본과 최초 AI 원본을 분리. 브라우저별/기기별 동기화 없음.
- 다운로드·복사는 브라우저 내에서 가능하도록 설계.

## MVP 품질 평가 초기 목표 (측정 전)

- 핵심 주장 근거 연결률 100%, 근거 시간 범위 유효성 100%
- 수동 근거 일치 샘플 95% 이상 목표, 검수 표본에서 근거 없는 주장 0건 지향
- 한국어 자연스러움 5점 척도 4점 이상 목표
- 분석 시간 10분 이내 비율 90% 이상 목표 (현재 미검증)
- 테스트 권장: 한국어 인터뷰/강의, 개발 시연, 슬라이드·그래프, 외국어, 자막 없는 영상 등 최소 24개.

## 기술 구성

Next.js 16 App Router, React 19, TypeScript, Tailwind CSS 4, shadcn/ui 친화적 컴포넌트 구조, Vercel; YouTube Data API; Redis REST 서버 사이드 quota; 기본 PoC AI REST 공급자; 브라우저 IndexedDB. 기본 UI 컴포넌트는 기존 스캐폴드에 추가 의존성을 만들지 않기 위해 Tailwind 기반으로 구현했으며 shadcn CLI 설정 파일을 포함한다. 정식 shadcn/Radix 컴포넌트 적용은 후속 접근성 QA에서 확장 가능.

## 기술 검증 게이트

- G1: 적법하게 영상에 접근 가능한 입력 경로 확보 및 제한 확인
- G2: 선택 무료 AI 제공자의 실제 무료 한도/상업적·개인정보 처리 조건 확인
- G3: 영상 근거·요약·전사 정확성 및 실시간 처리 성능 실험
- G4: 함수 시간 초과·브라우저 종료·네트워크 차단 시 예약 정산과 결과 복구 정책 개선
- G5: 개인정보·저작권·이용약관 정식 작성 및 상업적 배포 플랜 결정
