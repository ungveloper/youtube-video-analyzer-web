# v18 · 영상 처리 지연 감소 및 측정

## 목적
3분 내외 영상에 Agentic 탐색을 강제로 사용하는 v17 기본값을 개선하고, 실제 병목을 정량적으로 측정한다.

## 규칙
- 자동: `<300초`는 static, `>=300초`이고 Gemini 3.8 Flash는 agentic, Flash-Lite는 기존과 동일한 static. 사용자가 static/agentic을 명시적으로 선택하면 선택을 존중한다.
- 영상 URL은 기존 Gemini Interactions API 영상 입력 형식을 그대로 사용한다. 동영상 입력 후 지시문.
- 기본 분석(1회): 저지연 추론 수준(low), 짧은 영상 12,000 토큰 상한. 출력 정확성·시간 근거·품질 감사·후반부 경고 그대로 유지. 503·시간 초과가 나면 2회 자동 재요청하지 않고 사용자가 판단한다. 정밀 모드는 기존 재시도/후반부 검사 정책 유지.
- 시간 지정 원문: 기존 1회 텍스트 분석을 유지. 영상 처리 선택 UI는 사용 불가.
- 로깅: API 키, 영상 자막, 원문 데이터 기록 없이 요청 ID/모델/처리 모드/패스/지연시간/토큰/항목수 로깅.
- `analysis.timing`은 YouTube 메타데이터 조회 지연 및 분석 지연을 구분한다. 기존 브라우저 편집 저장 정책, 무료 모델 허용 목록, API 사용자의 과금 책임은 바꾸지 않는다.
- 품질을 희생해 무조건 5초를 보장하거나 근거 없는 결과를 채우지 않는다. Static과 Agentic은 동일 영상에서 사용자가 실제로 비교한다.
