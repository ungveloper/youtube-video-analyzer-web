# 개인용 분석 v2.0 — 세션 전용 결과와 아티클 복구

- IndexedDB 자동 저장과 `/history` UI/페이지를 제거했습니다. 분석 결과와 사용자 편집은 React 현재 탭 메모리에서만 유지합니다. 다른 URL 이동/새로고침/탭 종료 시 사라집니다.
- API 응답은 브라우저 화면으로 전달하며 서버에 결과 DB를 유지하지 않습니다. 무료 Gemini/YouTube 전송은 종전대로입니다.
- 결과를 보관하려면 다운로드(Markdown/TXT/PDF/Word)하거나 직접 복사하세요. 과거에 저장된 IndexedDB `youtube-video-analyzer` DB는 사용자의 동의 없이 자동 삭제하지 않습니다.
- 정밀 분석 전체 문서 작성이 일시적 HTTP/시간 제한/JSON 오류로 실패하거나 아티클이 너무 짧으면, 근거 맵 텍스트만 사용한 작은 아티클 전용 요청을 최대 1회 시도합니다. 무료 API 요청은 정상 2회, 1차 근거 추출 재시도 1회 + 아티클 전용 복구 1회를 합하면 최대 4회입니다.
- HTTP 429, 권한·모델 오류는 아티클 복구를 실행하지 않습니다. 아티클 전용 복구 시 요약/타임라인은 원본 근거 메모이며 전체 품질은 `partial`입니다.
- 근거가 없거나 Google 서버가 지속 실패할 때 완벽한 아티클을 만들어내지 않습니다. `TEMPORARY_HTTP` 실패를 사용자에게 알립니다. 유료 모델 자동 전환 없음.
- 이전 버전의 개인정보 안내/README 및 과거 PRD는 과거 상태를 기술한 변경 이력입니다. 최신 정책은 이 문서와 화면 표시를 우선합니다.
