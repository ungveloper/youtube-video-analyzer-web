# v1.7 · Google HTTP 500 정밀 분석 복구 정책

- 실패 로그: `pass=source-map`, `model=gemini-3.8-flash`, `HTTP 500`, `Internal error encountered`. 실제 Google 제공자 서버가 응답한 500 상태. 단일 기록으로 근본 원인은 확정 불가.
- v9 결함: `standard`에는 재시도 있었지만 `deep` 1차 근거 추출에는 재시도가 없었음.
- v1.7 수정: 정밀 원본 근거 추출 단계에만 일시적 408/5xx/시간초과 재시도 최대 1회. 429, 400~404, 결과 스키마 오류는 재시도하지 않음.
- 호출 상한: 정밀 정상 2회, 장애 시 최대 3회. 재시도 이유는 UI와 로그에 기록.
- 영상 근거 추출 thinking_level=low, 상세 문서 재구성은 medium(3.8). 유료 모델 자동 전환 금지.
- 실패하면 실제 오류를 그대로 분류하며 사용자에게 모델 변경 또는 나중에 재시도를 제안. 다른 무료 모델 비교는 사용자의 명시적 선택.
- 안전: 서버 API는 개인용 로컬 개발 전용. 기존 브라우저 결과는 보존. API 비밀키·응답 본문은 로그에 남기지 않음.
- 검증 필요: 실제 Gemini Free Tier 계정에서 500 재현 여부, 비정상 호출량, 복구 후 근거 정확성.
