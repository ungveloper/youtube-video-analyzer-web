# v16 — 알림 통합 및 분석 내용 보존

- Sonner를 다크 네이비/인디고 테마에 맞춰 앱 최상단에 한 번 마운트한다. 성공·실패·알림은 클릭 가능한 유의미한 동작에만 표시한다.
- 분석 성공/실패는 상세 상태를 화면에 유지하고 토스트는 간결하게 표시한다. 실시간 분석은 하나의 토스트 ID로 업데이트한다.
- 타임라인 자동 세분화 시 새 결과의 총 설명 길이가 기존의 85% 미만이면 전체를 대체하지 않는다. 항목 개수를 늘리려 설명을 소실하지 않는다.
- 영상 후반부 확인 여부는 마지막 **근거 종료 시점**을 사용하는 구조적 참고 지표로 표시한다. 타임라인 항목 개수나 마지막 **시작 시점**만으로 완성본을 '미완성'이라 단정하지 않는다.
- 상세 문서 생성 자체에 실패했거나 아티클이 복제/누락된 때만 '부분 분석' 배지를 사용한다. 구간별 내용 확인 여부는 원본 대조가 필요하다.
- 추가 Gemini 호출, DB/Redis, 브라우저 영구 저장은 도입하지 않는다.

## 설치
`sonner` 의존성은 Mac 적용 스크립트에서 `npm install --save-exact sonner@2.0.7`로 설치하며 package.json/package-lock.json의 변경분도 함께 커밋한다. 일반적인 토스트는 공식 shadcn/ui Sonner 패턴(`toast.success`, `toast.error`)을 따른다.
