# PRD v2.1 — 원문 우선·속도·시간적 범위 검사

- 라이브위키 FAQ 공개 설명: 자막이 있는 유튜브 영상의 자막 중심 추출·요약. 비공개 프롬프트·모델 및 구현은 알 수 없음.
- 사용자 제공 SRT/VTT 또는 시간표시 복사 원문(예: 0:00 다음 줄 발언)을 허용하며, 서버는 원본 시간을 유지. 자막 자동 다운로드/스크래핑 없음.
- 시간 지정 원문 제공 시 Gemini 텍스트 모델 호출 정확히 1회. 영상 URL 정밀 모드는 영상 근거 1회 + 문서 작성 1회(오류 복구 추가 요청 가능). 기본 영상 URL 분석은 1회.
- 1회 영상 URL 분석에도 타임라인 시작 시각의 영상 구간 분포를 검사. 후반 타임라인이 부족한 경우 완료처럼 가장하지 않고 부분 분석 표기. 구조 검사는 발화의 실제 사실성을 보증하지 않음.
- 무료 API 한도와 Google 과부하가 있는 경우 상세 분석은 실패할 수 있으며 유료 모델 자동 선택은 금지.
- 결과는 현재 화면에만 유지. 다운로드 전 페이지를 이동하면 복구되지 않음.
- 의료 영상의 문장을 그대로 사실로 단정하지 말고, 영상 화자의 주장과 별도 검증된 의학적 사실을 구별.
- 수용 테스트: 동일 원문 기준 타임라인의 후반 25% 포함, 원문에 있는 주요 논점 누락률, 아티클 중복도 및 1회 호출 지표.
