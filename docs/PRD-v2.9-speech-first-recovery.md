# v22 · 발언 중심 타임라인/누락 구간 복구

문제: 한 번의 Gemini 호출로 transcript와 편집자 timeline이 모두 생성되지만 화면은 요약문인 timeline을 먼저 사용해 발언을 잃는다. 03:22 영상의 02:12 이후 발언이 없는데도 정상 완료처럼 보인다.

수정: 모델에서 받은 transcript의 발언 문장을 변형 없이 시간순 렌더링한다. 발언 인식이나 시각이 정확하다는 의미가 아니며 AI 추정으로 표기한다. transcript가 없는 경우에만 요약 기반 기존 타임라인을 제공한다.

모델 출력에서는 transcript를 최우선 산출물로 지시하고 초반/중반/후반과 마지막 구간을 확인하도록 요청한다. 하나의 요청이 영상 전체를 보장하지는 않는다.

선택형 누락 보완: 발언 행의 시작/종료 시각 사이에 긴 공백이 있을 경우 사용자 체크에 따라 해당 구간만 영상 입력 1회로 재확인한다. 실제 확인된 문장만 추가하고 중복/영상길이 초과는 배제한다. Google 429/503이면 기존 부분 결과를 보여주고 새 주장을 생성하지 않는다. 기본 1회 요청, 보완 필요 시 최대 1회 추가, 503 재시도가 켜진 경우 최초 요청에 대한 1회 재시도 가능.

시간 지정 SRT/VTT 입력과 별도의 정밀 분석은 기존 경로를 보존한다. AI 재작성과 신뢰할 수 있는 실제 자막을 혼동하지 않는다.

서버 로그 analysis.speech_recovery, analysis.speech_recovery_failed, analysis.timeline_granularity 에서 음성 보완과 미해결 공백을 점검한다.
