# v23 · 시간 범위 제한과 실시간 개발서버 안전 패치

## 문제
- v22는 한 영상의 마지막 1분 발언을 보완하면서 모델이 반환한 시작/종료시간이 실제 보완 요청 범위에 들어오는지 검사하지 않았다. 따라서 후반부 대사가 00:02에 삽입되거나 중복됐다.
- `03:10~03:22 발화 없음` 같은 모델 추정 문장을 검증된 무음 정보처럼 보여줄 수 있었다.
- 패치 적용 중 dev 서버가 살아 있다는 이유로 적용을 아예 막았다.

## 변경
- 정확히 한 개의 누락 시간 범위를 우선 선택(후반 구간 우선).
- 보완 응답의 시각이 요청 범위 밖이면 폐기. 비정상적 압축·원본과의 시간 겹침·텍스트 중복도 폐기. 실패/거절 통계는 로그에 남김.
- 원본 발언이 확보되지 않으면 기존 발언 보존, 부분 분석 상태 유지. 내용·정확한 타임스탬프를 만들어 채우지 않음.
- 무음을 확정할 수 없는 Gemini 생성 제외 문구는 숨김.
- 활성 개발서버가 있어도 소스 적용은 허용. npm ci는 실행하지 않고 Next 빌드는 격리된 임시 프로젝트에서 실행. 기존 Node modules와 .next/dev를 보호.

## 제한
- 이는 오류/중복/비정상 시각의 **차단 장치**이지 실제 음성 정렬(ASR forced alignment)이 아니다. 원문 자막이 없다면 정확한 발언 시각을 보장할 수 없다.
