# v1.8 품질 개선 설계 / v11 패치

기준 Git SHA: `e7a56cbede0137990584eebe35588e32854201fe`

## 근거 조사
라이브위키 공식 FAQ(https://livewiki.com/ko/faq)에서는 자막으로 영상 주요 내용을 추출하고, 자체 학습 데이터와 프롬프트 체이닝을 개선한다고 설명합니다. 자막이 없는 영상은 지원하지 않는다고 밝힙니다. 서비스의 비공개 코드는 확인할 수 없습니다.

## 전·후
- 전: YouTube URL 멀티모달 입력 → LLM이 사실 근거 추출 → 또 다른 LLM이 문서 작성. 원문 발화 확보를 검증할 방법이 없고, 원문이 빈약하면 전 단계 품질이 제한됨.
- 후: **선택적 원문 입력 경로** 추가. 사용자가 적법하게 확보한 자막 SRT/VTT → 서버 측 시간/문구 결정적 파싱 → 1차 AI 논점 추출(텍스트만) → 2차 AI 문서 구성(텍스트만) → 근거 ID 검증/누락 자막 구간 표시 → 브라우저 IndexedDB 저장.
- 자막 미입력 시 기존 URL 직접 영상 분석은 유지. `partial`은 API 실패가 아닌 근거/콘텐츠 밀도 부족을 뜻함.

## 품질 체크리스트
1. 3분 이내 교육형 영상 SRT를 준비해 구간이 원래 순서대로 표시되고 타임스탬프를 누르면 해당 위치로 이동하는지 확인.
2. 구간 일부가 AI 타임라인에서 빠진 경우 `원문 자막 · 추가 구간`이 표시되는지 확인.
3. 스크립트 탭의 문구가 사용자가 제공한 시간코드 원문인지 비교.
4. 한국어 외의 원문 스크립트는 번역이 아니라 원문으로 표시된다는 안내 확인.
5. 근거 참조율 숫자를 실제 사실 검증률로 오인하지 않도록 라벨 확인.
6. 누락/형식 불량 SRT 또는 180,000자 초과 입력은 API 호출 전에 거절되는지 확인.
7. 사용자 자막 미제공 시 기존 URL 분석이 변경 없이 동작하는지 확인.
8. API 실패, Free Tier 제한 429, 중단, 기존 IndexedDB 열기·편집·다운로드 회귀 테스트.

## 제한 및 보안
- 사용자가 입력한 자막은 요청 중 AI 공급자에게 전달되며, Google의 무료 등급 데이터 정책이 적용됩니다. 본 서비스의 서버 DB에는 저장하지 않습니다.
- 오디오/자막 다운로드를 무단으로 수행하지 않으며 저작권/권한은 사용자가 확인해야 합니다.
- 소스가 정확하지 않으면 품질을 보증하지 않으며, 시간 ID의 형식 검사는 의미상 일치를 증명하지 않습니다.
- 약관/무료 한도와 모델 기능, 프로덕션 공개 전 정책 확인이 필요합니다.
- 기존의 모델 허용 목록, 로컬 환경 한정 API, 유료 모델 자동 미전환은 유지됩니다.
