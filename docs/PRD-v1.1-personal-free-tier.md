# PRD v1.1 보충: 개인용 무료 API 시험 모드

원본 `PRD-v1.0.md`는 향후 공개 SaaS로 확장할 때의 기준 요구사항으로 **보존**합니다. 현재 로컬 개발 단계는 다음처럼 제한적으로 운용합니다.

| 항목 | v1.0 공개 SaaS 목표 | v1.1 개인 테스트 |
|---|---|---|
| 로그인 | 없음 | 없음 |
| 데이터베이스/Redis | 무료 이용 횟수 집계 | **사용하지 않음** |
| 무료 분석 3회 | 공개 SaaS 운영 정책 | **개인용에서는 제거** |
| AI | 검증된 무료 공급자 우선 | Gemini 3.5 Flash-Lite(무료 티어가 명시된 프로젝트) 하나로 고정 |
| 공개 YouTube URL | 목표 | Interactions API Video URI 미리보기 활용 |
| 완료 결과 | 브라우저 저장 | IndexedDB 유지 |
| 공유 | 없음 | 없음 |
| 문서 편집/다운로드 | 필수 | 기존 코드 유지 |
| 접근 | 누구나 이용 | 로컬 Next dev 에서만 분석 가능 |
| 비용 | 공개 후 운영 모델 결정 | 과금 미연결 프로젝트 사용을 수동 검증해야 함 |

실제 실험 결과에 따라 모델 가용성, YouTube URL 처리, 타임라인 검증 정확도, 응답 시간은 수정이 필요할 수 있습니다. 서비스가 API 키의 Google Cloud Billing 연결 상태를 자동 조회하거나 강제로 차단하는 기능은 없습니다. 사용자 확인 플래그는 기술적 과금 보증이 아닙니다.

API 응답 오류: `FREE_LIMIT`(429) 발생 시 즉시 중단, 유료 모델로 자동 전환하지 않음. 배포 서버에서는 AI 실행 차단.
