# v25 · 짧은 영상 구간별 발언 타임라인 (실험 기능)

## 배경

2026-10-13 3분 22초 영상에서 공개 자막 `available:false`, 원문 17개, `00:~1:08` 이후 50초 공백 및 마지막 43초 누락. 후반부 시각을 검증하지 못하는 기본 단일 영상 프롬프트는 발언을 잘못 배치했다. 기존 `analysis.time_coverage.missingWindows:[]`은 발언 누락 여부를 뜻하지 않았다.

## 변경

- 실험 옵션 켜짐(기본), 120~300초, Standard + Static + 공개 자막 없음일 때만 비중복 세 구간으로 영상 입력을 나누어 **하나의** Interactions 요청에 첨부한다. `[0,round(d/3)], [round(d/3),round(2d/3)], [round(2d/3),d]`.
- Interactions REST 스키마에 맞춰 `processing:{type:'static',start_offset:'0s',end_offset:'67s'}` 형식을 사용한다.
- JSON `segmentTranscripts` 내 `segmentIndex`, `lines[]` 필드의 초는 해당 구간 시작점을 0초로 한 상대 시각. 절대 시각으로의 변환은 코드만 한다.
- 이전의 글로벌 시각 전사는 해당 경로에서 폐기. 구간 누락, 중복, 경계 바깥·과밀 발화는 제거하고 로그에 기록. 후반부 누락 시 `partial` 유지.
- 근거(evidence) 분포와 발언(speech) 누락 로그를 분리. 자막 사용·정밀·Agentic 등 기존 처리 경로는 유지.

## 한계

- 같은 동영상을 세 조각으로 전달하는 방식은 Google의 공개 Interactions API 명세 기반이지만 실제 영상 aFmUl65-2-c에 대한 실시간 API 검증이 아직 없다. 특히 YouTube URI에 구간 제한을 적용하는 경우 400 또는 다른 제공자 오류가 가능하다. 429를 소모하지 않도록 자동 추가 분석은 기본 비활성.
- 영상의 구간별 시각은 AI 추정값으로 원본 음성과의 프레임 정확도 또는 축자 전사를 보장하지 않는다. 정확한 자동 자막이 제공되지 않으면 최종 부분 분석이 나올 수 있다.
- 검증 목표: 음성의 시간 밀림 감소, 마지막 구간 음성 회수, 기존 1회 Gemini 요청 유지, 결과 무단 보충 금지.
