# v4.1 · 음성 발언 보존 우선 및 중반 누락 교차 검증

## 실제 회귀 사례 (2026-10-14 사용자 비교)

202초가량의 편집 영상에서 기존 앱 전사와 사용자가 제공한 외부 시간 지정 전사를 비교했다. 기존 앱은 정확한 의학 용어를 많이 복원했으나, 외부 전사 기준 약 01:46~01:59의 간헐적 파행·통증 부위, 02:08~02:36의 척추관 협착증과 카트 비교를 상당 부분 누락했다. 또한 다리 온도·창백함 발언을 약 22초 앞당겼다. 사용자가 제공한 별도 촬영 대본은 원본 촬영 시간축(약 16분)으로, 편집 영상의 절대 초를 검증하는 정답이 아니다.

이 문서는 특정 영상만을 위한 코드가 아니다. 참고 문구는 **회귀 테스트의 입력 자료**로만 존재하며 실제 앱 로직에 특정 질병명, 화자명, 영상 ID, 예상 시각을 하드코딩하지 않는다.

## 변경

1. `lib/segmented-speech.ts`의 기존 엄격한 코어 소유권 필터는 유지한다. 새 `salvageRejectedSpeech`는 실제 Gemini 개별 클립 응답을 재검사하여, 클립 *담당 코어 안*에서 반환했지만 **시각 겹침 때문에 버려진 서로 다른 발언**을 복구한다. 잘못된 입력/터무니없는 발화 속도/이웃 문맥 시작/반복 문구는 제외한다.
2. 각 구간의 반환 개수, 부적합·문맥·중복 제거 개수, 복구 발언 개수 등을 `analysis.speech_preservation_audit`로 기록해 전사 단계 유실을 추적한다. 발언 원문이나 API 키를 로그에 쓰지 않는다.
3. 기존 여섯 원본 영상 클립 분석 후, 시간 예산이 허용할 때 **두 개의 서로 다른 중반부 영상 구간**을 추가로 직접 듣는다. 각 34~52초, 보통 영상 전체의 39~82%를 이중 검토한다. 기존 발언 텍스트를 프롬프트로 주지 않아 AI의 확인 편향을 줄이고, 실제 신규 발언만 추가한다.
4. 시간 충돌이라는 이유만으로 신규 발언을 버리지 않는다. 이미 존재하는 문장 2개 이상이 독립 재분석에서 3~28초 범위의 일관된 시차를 보여야만 해당 두 문장의 **추정** 시각을 조정한다. 한 문장만 일치하거나 시차가 엇갈리면 시각을 유지한다.
5. 기존 503→다른 허용 무료 모델 한 번 확인/429 즉시 중단, API 호출 대기 예산, 문장 병합, 공개 자막 우선, SRT 업로드, 서버 무저장 구조는 변경하지 않는다. 추가 재분석이 작동한 경우 기존 1회 공백 재검토/1회 시계 재검토는 중복 실행하지 않는다.

## 한계 및 검증

- 추가 독립 영상 요청은 최대 2회로 무료 할당량을 더 소모할 수 있다. Gemini 서버가 느리면 기존 제한시간 때문에 생략될 수 있다.
- 텍스트 보존은 실제로 들리지 않는 내용을 보충하거나 없는 발화를 만들지 않는다. 원본 API 응답에 없던 내용은 별도 영상 입력 재분석에서 실제로 확보해야만 추가한다.
- Google의 영상 자체 분절/시간 추정은 실제 음성 수준 강제 정렬이 아니다. 시간 정확성을 보증하지 않는다.
- 사용자가 제공한 외부 전사본에는 오타가 있을 수 있고, DOCX는 편집 영상과 타임라인이 다르다. 회귀 테스트는 음성 추출의 재현 가능한 처리 규칙을 검증하는 *합성 영상 응답*이며 실제 Google API 테스트를 대체하지 않는다.
